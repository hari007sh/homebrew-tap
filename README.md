# Aerie Homebrew Tap

This is the official Homebrew tap for [Aerie](https://aerie.work), a native macOS notch workspace.

The tap remains private until the first stable, notarized public release is available. After launch, install Aerie with:

```sh
brew install --cask hari007sh/tap/aerie
```

Aerie uses Sparkle for signed automatic updates. The cask points to the same notarized DMG published on the Aerie website.
